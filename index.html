ストレージ道場

LPIC-1 のファイルシステム・マウントの実習用シミュレータです。ディスクを観察し、区画を作り、ファイルシステムを作ってマウントし、fstab で永続化し、壊れたときの点検・修復、容量管理、LVM による柔軟な容量変更まで、ブラウザの中の仮想マシンで体験します。何を打っても本物のマシンには影響しません。

📘 この道場って何？（はじめての方はここから）

新しく追加したディスクを「使える状態」にするには、順番があります。本棚にたとえると、①本棚そのもの（ディスク）を用意 → ②仕切り板で段に分ける（パーティション）→ ③本の並べ方・索引のルールを決める（ファイルシステム）→ ④部屋の出入口に据え付ける（マウント）→ ⑤引っ越しても自動で据え付ける（fstab）。この流れを、手を動かして覚えます。

  1. ディスク本棚
  2. パーティションfdisk
  3. ファイルシステムmkfs
  4. マウントmount
  5. 永続化/etc/fstab
  • ステージ1 観察：lsblk・df・blkid・fstab で、いまの構成を読む
  • ステージ2 作る・使う：失敗から入り、fdisk → mkfs → mount → umount まで
  • ステージ3 永続化：再起動で消える体験 → fstab → 壊れた fstab で緊急モード → nofail・ラベル
  • ステージ4 点検・保守：fsck と xfs_repair、tune2fs、スワップ、du と df、iノード枯渇、マウントオプション（noexec・remount）
  • ステージ5 LVM：PV → VG → LV の作成、lvextend ＋ resize2fs / xfs_growfs、縮小の正しい順番、vgextend、pvmove、後片付け

使い方：①左のミッションを読む → ②右の黒い画面をクリックしてキーボードで入力 → ③ミッション内のチェックが全部 ✓ になればクリア。右のディスク構造図は、操作に合わせてリアルタイムに変わります。分からない言葉は 「📖 用語メモ」、詰まったら 「ヒント」を開いてください。

    点検・修復

    sudo fsck [-fn y p] DEV
    ext の点検（-n 点検のみ / -y 全部yes / -p 安全なものだけ / -f 強制）。アンマウント必須
    sudo xfs_repair [-n] DEV
    XFS の修復（アンマウント必須。-L はログ破棄）
    sudo tune2fs -l DEV
    ext の仕様書を表示（-m 予約% / -O ^has_journal / -j）
    sudo dumpe2fs -h DEV
    ext のヘッダ情報
    xfs_info DIR / xfs_admin -l DEV
    XFS の構成 / ラベル表示

    スワップ・容量

    sudo mkswap DEV
    スワップとして初期化（mkfs 相当）
    sudo swapon / swapoff
    有効化 / 無効化（-a は fstab の全部）
    swapon --show / free -h
    スワップの確認
    du -sh / du -h -d 1 DIR
    ディレクトリごとの使用量
    ls -ld ディレクトリ
    ディレクトリ自体の持ち主と権限を見る（-d が無いと中身の一覧）
    sudo chown ユーザー ディレクトリ
    持ち主を変える（マウント先に一般ユーザーが書き込めるようにする）
    sudo dd / fallocate / chmod 600
    スワップファイルの作成と権限
    mount -o remount,ro|rw|exec DIR
    つなぎ直さずにオプション変更

    LVM

    sudo pvs / vgs / lvs
    PV / VG / LV の一覧（詳細は pvdisplay / vgdisplay / lvdisplay）
    sudo pvcreate DEV…
    PV にする（既存の署名があると Wipe 確認）
    sudo vgcreate VG DEV… / vgextend VG DEV
    VG を作る / ディスクを追加する

    LV を作る（-l 100%FREE で空き全部）
    sudo lvextend [-r] -L +1G /dev/VG/LV
    LV を広げる（-r で中身も一緒に）
    sudo resize2fs DEV / xfs_growfs DIR
    ext / XFS を広げる（マウント中OK）
    縮小：umount → e2fsck -f → resize2fs → lvreduce
    ext4 のみ。順番厳守。XFS は縮小不可
    sudo pvmove PV → vgreduce → pvremove
    ディスクの入れ替え
    lvremove → vgremove → pvremove
    撤去（作った順の逆）
